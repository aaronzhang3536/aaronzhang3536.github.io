## 真实手机数据库与公网接口

使用 2 个独立临时公共账号和 1 个临时第二应用，通过真实 HTTPS 请求验证。最终每个检查的最近结果共 35 项通过；测试脚本为 [verify_live.py](../phone-backend/verify_live.py)。覆盖：

- 公共注册、同账号另一应用登录、/me 身份确认。
- 精确来源 CORS 预检 204、陌生 Origin 403、匿名 401。
- 收藏创建、读取、取消收藏、删除；服务端删除墓碑仍在。
- 第二用户访问他人 UUID 的 GET/PATCH/DELETE 均 404，列表独立。
- 第二应用令牌对本应用 GET/PUT/POST/DELETE 均 403；错应用 URL 403，第二应用自己的空间为空。
- 词条/SRS、每日统计、道场计数、计划取消、节奏成绩、累计次数、最佳用时、阅读字号、术数历史、Babel 手册真实保存并逐值读回一致。
- 重放同一 UUID 返回 replayed=true，版本不增加；旧 base 返回 409。
- AI 配置等排除字段被 400 拒绝，整个批次不部分落库。
- 手册重置后，旧客户端快照被 409 拒绝，不能恢复旧星级。
- **真实 runit 服务重启**：后端 PID 从 30965 变为 31760，随后重新请求，版本和完整业务快照逐值相等。未重启整台手机。
- 仅将临时账号的本应用会话在数据库中设为已过期，接口返回 401；另一应用会话仍 200。
- 公共退出接口成功后原令牌不可重用，其他应用会话仍有效。

公网测试初次遇到非 JSON 边缘响应，另有一次 TLS EOF；未关闭 TLS 校验、未使用固定边缘地址绕过正常 DNS。测试工具对传输错误加入有限重试，最终使用普通域名完成全部请求；不能据此声称网络从不中断。测试脚本的 HTTP 响应头匹配已按大小写不敏感处理，文件读取明确使用 UTF-8。

## 边界

- 本次验证服务进程重启持久化，没有执行整机重启，也没有重新证明长时间锁屏、VPN 或家庭网络的稳定性。
- 同一数据类别在两台设备上同时修改时，需要用户选择保留版本；独立类别自动合并。没有声称实现无冲突的任意字段级合并。
- 原 EdgeOne 身份不自动映射到公共账号；旧数据通过明确的访客/文件导入迁移。没有替换 GitHub 评论，也没有上传出生信息、位置缓存或 AI 密钥。
- 测试账号、第二测试应用、测试记录与令牌在最终发布核验后按确切名单删除；真实用户、订单和授权不在清理范围。
